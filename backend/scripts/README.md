# Backend Scripts — Dev Tools

Ці скрипти НЕ є частиною додатку і НЕ підключені до `main.py`.
Використовуються тільки для розробки та адміністрування.

## Скрипти

| Файл | Призначення |
|------|------------|
| `seed.py` | Заповнення бази даних тестовими даними |
| `test_api.py` | Ручне тестування API ендпоінтів |
| `migrate_language.py` | Одноразова міграція мовних даних (вже виконана) |
| `migrate_sqlite_to_mysql.py` | Міграція з SQLite → MySQL (вже виконана) |
| `sync_shop.py` | Синхронізація магазину |

## Запуск
```bash
cd backend
python scripts/seed.py
```

> ⚠️ НІКОЛИ не запускайте seed.py у продакшені — він перезапише дані!
